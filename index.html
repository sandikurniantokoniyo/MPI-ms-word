Materi Pembelajaran: Microsoft Word

Daftar Bab Materi

1. Pengenalan Microsoft Word

Microsoft Word adalah perangkat lunak pengolah kata (word processor) terpopuler yang dikembangkan oleh Microsoft. Aplikasi ini merupakan bagian utama dari paket aplikasi perkantoran Microsoft Office.

Fungsi-Fungsi Utama Microsoft Word:

  • Membuat Dokumen Baru: Digunakan untuk menyusun surat, laporan, makalah tugas sekolah, proposal, hingga buku.
  • Mengedit Naskah: Memudahkan mengoreksi ejaan kata, mengubah kalimat, dan menyusun kembali susunan tulisan.
  • Memformat Teks: Memperindah penampilan dokumen dengan variasi jenis huruf, warna, ukuran, dan jarak antarbaris.
  • Mencetak Dokumen (Printing): Mengatur ukuran kertas dan pencetakan file fisik dengan rapi.

Catatan Format File: Format ekstensi standar file dokumen Microsoft Word versi modern (2007 ke atas) adalah .docx. Sedangkan versi lama (2003 ke bawah) menggunakan format .doc.

2. Antarmuka (Interface) Word

Mengenal bagian-bagian pada layar kerja Microsoft Word sangat penting agar kerja lebih efisien:

Quick Access Toolbar

Terletak di pojok kiri atas. Berisi tombol pintas seperti Save, Undo, dan Redo.

Title Bar (Baris Judul)

Menampilkan nama file dokumen yang sedang aktif terbuka di bagian atas layar.

Ribbon

Area menu utama yang berisi Tab (Home, Insert, Layout) dan grup ikon perintah.

Ruler (Penggaris)

Penggaris horizontal & vertikal untuk mengatur perataan paragraf dan batas margin.

Document Area

Lembar kerja putih utama tempat mengetik teks dan memasukkan objek visual.

Status Bar

Bilah di bawah layar yang menunjukkan nomor halaman, jumlah kata, dan tombol Zoom.

3. Manajemen Dokumen Dasar

Membuat Dokumen Baru

Langkah: Tab File > New > Blank Document.

Shortcut: Ctrl + N

Menyimpan Dokumen

Langkah: Tab File > Save / Save As.

Shortcut: Ctrl + S

Membuka File Simpanan

Langkah: Tab File > Open > Pilih lokasi file.

Shortcut: Ctrl + O

Mencetak Hasil

Langkah: Tab File > Print > Pilih Printer.

Shortcut: Ctrl + P

5. Menyisipkan Objek (Tab Insert)

Tab Insert berfungsi menyisipkan elemen visual dan tabel ke dalam dokumen:

Table (Tabel)

Membuat susunan data berkolom dan berbaris agar disajikan secara tertata.

Pictures (Gambar)

Memasukkan foto atau berkas gambar dari penyimpanan komputer ke lembar kerja.

Shapes (Bentuk Geometris)

Menyisipkan garis, panah, diagram kotak, lingkaran, bintang, dan bentuk visual lainnya.

Chart (Grafik Data)

Visualisasi statistik angka dalam grafik batang, garis, atau diagram lingkaran (pie).

6. Layout & Ukuran Halaman

Pengaturan ukuran kertas dan tata letak terdapat pada menu Tab Layout:

Margins (Batas Tepi)

Mengatur jarak kosong tepi kertas (Top, Bottom, Left, Right) ke teks.

Orientation (Arah)

Pilihan posisi cetak kertas: Portrait (Tegak) atau Landscape (Mendatar).

Size (Ukuran Kertas)

Menentukan jenis ukuran fisik kertas cetak seperti A4, Letter, Legal, F4.

7. Shortcut Keyboard Penting

Penguasaan kombinasi tombol keyboard membuat pengetikan menjadi jauh lebih cepat:

Membatalkan Perintah (Undo) Ctrl + Z
Mengulang Perintah (Redo) Ctrl + Y
Menyalin Objek (Copy) Ctrl + C
Menempel Objek (Paste) Ctrl + V
Memotong Objek (Cut) Ctrl + X
Memilih Semua Teks (Select All) Ctrl + A

Pengaturan Google Sheets

Kode Google Apps Script (GAS):

Buka Google Sheets > Ekstensi > Apps Script, tempelkan kode berikut:

function doPost(e) {
  try {
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var data = JSON.parse(e.postData.contents);
    sheet.appendRow([
      data.tanggal || new Date().toLocaleString("id-ID"),
      data.nama,
      data.kelas,
      data.skor,
      data.benar + " / " + data.total
    ]);
    return ContentService.createTextOutput(JSON.stringify({"result":"success"})).setMimeType(ContentService.MimeType.JSON);
  } catch(err) {
    return ContentService.createTextOutput(JSON.stringify({"result":"error", "message": err.toString()})).setMimeType(ContentService.MimeType.JSON);
  }
}
